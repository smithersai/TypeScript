# Language improvement proposals

Will decides each VibeLang language decision as a LIP, one at a time. The most fundamental decisions come first, and the most controversial come next. Each accepted LIP is recorded here with Will's words. Where an accepted LIP disagrees with the specification, the LIP wins until the specification is rewritten to match it.
